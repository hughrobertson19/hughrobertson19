**Built as learning projects:**
- [shayke-public](https://github.com/hughrobertson19/shayke-public): Shayke, an applied learning project. How I stop AI agents gaming their own scores: the scorer lives in its own repo, simulated sellers test the product every night, and the gaps are published. Includes a runnable quote check for AI judges.

An AI client's writes go through a propose then confirm step; for the fields it guards, the server rejects the write if the record changed in between. Tested against a real Salesforce Developer org.
- [screen-capture-md](https://github.com/hughrobertson19/screen-capture-md): a launchd-triggered pipeline that turns a screen recording into a transcribed, timestamped markdown doc.
