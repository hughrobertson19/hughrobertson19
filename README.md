**Built as learning projects, each verified against something real:**
- [mcp-salesforce-server](https://github.com/hughrobertson19/mcp-salesforce-server) — a standalone MCP server where an AI client can only write to Salesforce through a propose-then-confirm step. The before-state is held server-side so it can't be forged or skipped, and every write is re-verified against the live record. Tested against a real Salesforce org, including a genuine concurrent-edit rejection.

- [screen-capture-md](https://github.com/hughrobertson19/screen-capture-md) — a launchd-triggered pipeline that turns a screen recording into a transcribed, timestamped markdown doc.
